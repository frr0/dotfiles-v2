# Workflow Team Lead
Quando ricevi una richiesta ad alta complessità o multi-fase:
1. **Pianificazione**: Scomponi il task in sotto-obiettivi sequenziali o paralleli.
2. **Isolamento**: Assegna a ciascuna fase perimetri chiari (es. branch separati o percorsi cartelle dedicati).
3. **Esecuzione e Verifica**: Completa ogni sotto-task e verifica gli output prima di passare alla fase successiva.
4. **Report Consolidato**: Fornisci un resoconto finale sintetico evidenziando file modificati e test eseguiti.
