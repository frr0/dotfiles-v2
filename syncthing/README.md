# Syncthing Configuration

This directory contains the configuration template for [Syncthing](https://syncthing.net/), providing continuous decentralized file synchronization across devices (e.g. personal Obsidian Vault sync between laptop and phone).

## Security & Secrets Management

Syncthing generates and uses sensitive cryptographic materials that **must never be committed to Git**:

1. **Private Keys & TLS Certificates**:
   - `key.pem` (Device TLS private key)
   - `https-key.pem` (HTTPS Web GUI private key)
   - `cert.pem` / `https-cert.pem` (Public certificates)
   *These files are automatically generated by Syncthing on each individual machine upon first start and are excluded via `.gitignore`.*

2. **Web GUI & REST API Key**:
   - Located in `<gui><apikey>...</apikey></gui>`.
   - In `config.xml`, this value is replaced with a placeholder: `GENERATE_OR_INSERT_SECRET_APIKEY_HERE`.
   - The installer (`install.sh`) automatically generates a secure random 32-character API key when copying this template to a new machine if one does not already exist.

3. **Index & Database State**:
   - `index-v2/` contains the local database and synchronization indices, strictly excluded from version control.

## Synced Folders & Devices

- **Obsidian Vault**: Synchronized across devices under `~/Documenti/Obsidian Vault`.
- **Paired Devices**:
  - `cachyos-Thinkpad` (Local Linux workstation)
  - `Motorola Edge 50 Neo` (Mobile device)

## Directory Structure

On modern Linux systems (XDG Base Directory specification):
- Configuration & State: `~/.local/state/syncthing/` (or `~/.config/syncthing/`)
  - `config.xml` (Active configuration)
  - `cert.pem` & `key.pem` (Device TLS identity)
  - `https-cert.pem` & `https-key.pem` (Web GUI SSL certificates)
  - `index-v2/` (LevelDB metadata)
